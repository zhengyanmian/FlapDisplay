## 二、模组简介（正文开头）

翻牌万象（FlapDisplayPlus）是一个机械动力（Create）的扩展附属模组。原版翻牌显示器只能显示文字，本模组让它变成一块真正的"屏幕"——可以播放本地图片、GIF 动图和视频，显示现实时间、游戏时间、天气、TPS 等实时信息，并可与网络音乐机（Net Music）联动，在翻牌上显示歌曲封面、歌名与逐行同步的歌词。

模组严格遵循机械动力原版设定：翻牌显示器需要**动力（转速）**才会显示内容，断电即停。

## 三、详细介绍

### 媒体显示

| 类型 | 格式 | 说明 |
|------|------|------|
| 图片 | PNG / JPG / BMP / WebP | 自动按翻牌尺寸等比缩放 |
| 动图 | GIF | 逐帧解析，按帧率循环播放 |
| 视频 | MP4 / M4V / MOV / MKV / AVI / WebM / FLV / WMV / TS | 双解码后端，见下文 |

**双解码后端**：

- **FFmpeg 后端（推荐）**：性能强、格式全，支持 H.264 / H.265 / AV1 编码。游戏内缺失解码器时会**自动下载**（聊天框提示开始/完成/失败），也可手动将 `ffmpeg.exe` 放到游戏根目录或 `config/flapdisplayplus/` 目录。
- **JCodec 兜底后端**：纯 Java 实现（MP4/H.264），无需任何外部程序。没有 FFmpeg 时自动使用，保证任何环境都能播放。

视频最大分辨率与帧率可在配置中调整，以适配不同性能的电脑。

### 网络媒体

- 支持**URL 直链**（图床、CDN、直链视频等）
- 支持**视频网站链接**（B站、YouTube 等），通过用户自行安装的 `yt-dlp` 解析（模组不内置任何站点逆向；未安装 yt-dlp 时直链功能不受影响）
- **边下边播**：无需等待整个文件下载完成
- **缓存管理**：重复播放直接命中缓存，缓存容量可配置、自动清理

### 实时信息源

- **现实时间**：系统时钟，格式可自定义
- **游戏时间**：世界天数与时刻
- **天气**：当前天气状态
- **TPS / MSPT**：服务器性能监控

### 网络音乐机联动（可选，需安装 Net Music）

- 显示当前播放曲目的**专辑封面**
- **歌名 / 歌手**滚动显示
- **歌词逐行同步**，支持翻译歌词双行显示
- **网易云音乐 / QQ 音乐**多平台搜索（VIP 歌曲红字标识）
- QQ 音乐**扫码登录**与换号
- 刻录机界面可制作**媒体唱片**

### 使用方法

1. 放置**翻牌显示器**，用**显示链接器**指向它
2. 打开显示链接器界面，选择"媒体源"
3. 从本地文件选择图片/视频，或粘贴链接
4. 给翻牌供能（需要转速），画面即可显示

### 媒体校准指令

```
/fdpcal x|y|inset|ix|iy|z <值>   # 调整画面位置（支持 +n / -n 相对值）
/fdpcal show                     # 查看当前校准值
/fdpcal reset                    # 重置
/fdpcal save                     # 保存到配置文件
```

提示：从侧面看媒体与面板有错位时调 `z`（深度视差）；正面边距用 `ix` / `iy`。

### 行为细节

- 打开游戏菜单（ESC）时画面与声音自动暂停
- 清空媒体、拆除方块后立即停止播放，不会残留"幽灵声音"
- 显示链接器无转速时媒体停止显示（与原版翻牌一致）

## 四、常见问题（FAQ）

**Q：视频播放卡顿？**
A：确认 FFmpeg 已启用（日志中搜索"FFmpeg"）；高分辨率视频可在配置中调低 `media.videoMaxDim`（如 512）与 `media.videoFps`（如 24）。

**Q：没有转速/断电后画面消失了？**
A：这是刻意设计，与原版翻牌显示器一致——需要动力才会显示。给翻牌接上动力即可。

**Q：颜色不对/画面错位？**
A：使用 `/fdpcal` 指令校准；侧面错位调 `z`，正面边距调 `ix`/`iy`，调好后 `/fdpcal save` 保存。

**Q：B站/YouTube 链接无法播放？**
A：需自行安装 yt-dlp 并在配置中填写路径（`Mods → 翻牌万象 → 配置 → 媒体 → yt-dlp 路径`）。

**Q：音乐联动不生效？**
A：确认已安装网络音乐机（Net Music），且版本匹配 1.21.1。

**Q：是双端模组吗？**
A：是。客户端与服务端都需要安装。
