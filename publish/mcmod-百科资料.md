## 一、操作步骤

1. 登录 mcmod.cn（支持 QQ 登录），首页右侧点「添加模组」，或直接打开 `www.mcmod.cn/class/add`。
2. 按第二节逐项填写；编辑器中粘贴第三节简介正文。
3. 封面图：将本目录 `mcmod-cover-240x150.png`（240×150，百科封面规格）通过编辑器图片按钮上传到百科图床，再把得到的站内图片地址填入「封面」栏（官方要求封面使用站内地址）。
4. 普通用户提交时需填写表单底部的图片验证码（2 个字符）。
5. 提交后到「个人中心 → 我的编辑」跟踪审核状态；被退回会注明原因，修改后重新提交。
6. 收录后在模组页面用「模组关系」功能建立：前置「机械动力」，软依赖「网络音乐机」。

## 三、简介正文（直接粘贴，纯文本）

翻牌万象（FlapDisplayPlus）是一个机械动力（Create）的附属模组，将翻牌显示器扩展为媒体显示设备。模组支持在翻牌显示器上显示图片、GIF 动图、视频与实时信息，并可与网络音乐机（Net Music）联动，显示音乐封面、歌曲信息与同步歌词。模组遵循原版设定，翻牌显示器需要在具有转速的情况下才会显示媒体内容，断电后停止显示。

模组基于 Minecraft 1.21.1 与 NeoForge 21.1 开发，当前版本 1.0.0，需要前置模组机械动力 6.0.10 及以上版本，客户端与服务端需要同时安装。安装网络音乐机后自动启用音乐联动功能，未安装时其余功能不受影响。

媒体显示。模组支持三类媒体内容。图片支持 PNG、JPG、BMP、WebP 格式，画面按翻牌尺寸等比缩放，最大边长可在配置中调整。动图支持 GIF 格式，逐帧解析并按帧率循环播放。视频支持 MP4、M4V、MOV、MKV、AVI、WebM、FLV、WMV、TS 容器格式。视频解码提供两种后端：FFmpeg 后端支持 H.264、H.265、AV1 编码；JCodec 后端为纯 Java 实现，仅支持 MP4 容器的 H.264 编码，用于在无 FFmpeg 的环境下兜底。游戏内缺少 FFmpeg 时，模组在玩家进入世界后自动从镜像源下载，下载的开始、进度与结果在聊天栏提示，也可以手动将 ffmpeg.exe 放置在游戏根目录或 config/flapdisplayplus 目录下。视频的最大边长与帧率可在配置中调整，以适配不同性能的设备。

网络媒体。模组支持 URL 直链播放，可显示图床、CDN 与直链视频。视频网站链接（如哔哩哔哩、YouTube）通过用户在本机安装的 yt-dlp 程序解析，模组自身不包含任何站点的接口逆向；未安装 yt-dlp 时，直链播放功能不受影响。网络视频支持边下边播，无需等待整个文件下载完成。同一链接的重复播放会命中本地缓存，缓存容量上限可在配置中调整，超出上限后按最近最少使用原则自动清理。

实时信息。翻牌可直接显示现实时间（格式可自定义）、游戏内时间与天数、当前天气，以及服务器的 TPS 与 MSPT 数据。

网络音乐机联动。安装网络音乐机后，翻牌可显示当前播放曲目的专辑封面，滚动显示歌名与歌手，逐行同步显示歌词，支持译文歌词同时显示。模组提供网易云音乐与 QQ 音乐的搜索，搜索结果中的 VIP 歌曲以红字标识。QQ 音乐支持扫码登录与更换账号。在刻录机界面可将歌曲制作成唱片。

使用方法。放置翻牌显示器，将显示链接器指向它，打开显示链接器界面并选择媒体源，从本地文件选择图片或视频，或粘贴媒体链接，确认后为翻牌提供转速，画面即可显示。

媒体画面提供校准指令。/fdpcal x、y、inset、ix、iy、z 加数值可调整画面位置，数值支持 +n 与 -n 的相对写法。/fdpcal show 查看当前校准值，/fdpcal reset 恢复默认，/fdpcal save 将当前值写入配置文件。从侧面观察媒体与面板存在错位时调整 z 参数，正面边距使用 ix 与 iy 参数调整。

配置项通过游戏内模组菜单进入，界面沿用机械动力的黄铜风格。常用配置包括：视频最大边长（默认 720）、视频帧率上限（默认 24）、图片最大边长（默认 2048）、网络缓存上限（默认 512 MB）。

注意事项。JCodec 后端仅支持 MP4 容器的 H.264 编码，完整格式支持需要 FFmpeg。视频采用软件解码，播放高分辨率长视频时建议在配置中降低最大边长与帧率。流媒体清单（m3u8 与 dash）不受支持，模组按完整文件下载后播放。
